## Roll-up summary

### Fork "official" claim

Not official, but it is accurate for what it covers. The fork is by Fang-Pen Lin (MakerRepo, MIT). It calls itself "a build123d implementation of openGrid", and opengrid.world links it as its only build123d library (openGrid-docs PR #27). Its Full board, edge-connector negative, Multiconnect round/slot cutters and slot opening differ by 0 mm³ from David D's official STEP files (Printables model 1214361). No fork value contradicts either PDF.

Fork defects found against the official STEPs:

- `RoundHead`, `Slot` and `SnapInSlot` have no detent dimple.
- The `SnapInSlotCutter` offset is 0.795, not 0.759.
- The `SnapInSlotCutter` tail is 28 mm, not 26.5.

The fork has no Lite/Heavy boards, screw holes, positive connector, snaps, threads or openConnect parts. See [fork-provenance.md](fork-provenance.md).

Where the SCAD sources and the official STEPs disagree, the official STEPs side with the fork. Examples: the edge-connector neck is R2.7951 with a 5.134 mouth in the official STEPs (SCAD: R2.7, 5.3), and the Multiconnect slot-opening radius is 11.0.

### Resolution status

All 31 fix issues above are closed. Each child report has a "Resolution" entry for every fixed item: the issue ref and the new value measured on the built geometry.

- **jmq8 decision:** the official Edge Connector STEPs take precedence over the SCAD sources. Both the pocket and the positive connector now differ from the official files by 0 mm³ (symmetric difference).
- **Known deviation (r5tq):** the Blunt-thread expanding snap is about 14 mm³ off the SCAD render, because the stacked-segment SCAD build is infeasible in OCC. Details are in [snap-body.md](snap-body.md).
- **Verification after the fixes:** `uv run pytest tests/test_opengrid.py -n 0` passes (133 tests), and `basedpyright` reports 0 errors. `output/*.step` was regenerated with `examples/main.py`. Fixing the type errors also turned up a crash in `examples/main.py`, which still used a removed connector config field; it is fixed.

### Spec ambiguities (no fix filed; maintainer decision)

- Screw head recess default: the PDF gives Ø6.6; SCAD and ours use Ø7.2 ([board-full.md](board-full.md)).
- Multiconnect on-ramp mouth radius: ours and the generator use 11.65, BOSL 11.9, legacy 12, and the official STEP and fork 11.0 ([multiconnect-profile-parts.md](multiconnect-profile-parts.md)).
- Lite snap click hole: current QuackWorks uses 1.5; ours, opengrid-projects and the official STEP use 2.8 ([quackworks-update-e0c1cb7.md](quackworks-update-e0c1cb7.md)).
- Several directional snap details differ between the official STEPs and opengrid_snap_lib: back side cut, nub base width, lite nub flank angle and uninstall notch ([snap-body.md](snap-body.md)).
- Thread end chamfers differ between the PDF and SCAD ([snap-threads.md](snap-threads.md)).
- openConnect coin slot thickness: the SCAD library default is 2.4 and the customizer default is 2.2 ([openconnect.md](openconnect.md)).
- The positive adjacent connector has no SCAD definition; the official Edge Connector STEP is the only reference.
